## Definisi (disepakati user)

- Yang dihitung **SKU** (prefix 2 segmen, mis. `TYT-AVZ`) = 1 cover fisik,
  BUKAN nama produk. Mobil kembar ikut dipertahankan lewat SKU pasangannya
  -> **100 SKU = 110 nama mobil** di listing UA. User konfirmasi: "ini
  berarti top 100 SKU ya" -> ya.
- Status berlaku per MOBIL, semua tier (Reguler/Premium/Exclusive).
- Unit sama -> diurut nilai penjualan (Rp) terbesar.
- Data: `MOBIL_TERLARIS_BIGSELLER.xlsx`, 1 Apr - 16 Sep 2026 (169 hari),
  4 toko gabungan, Shopee + TikTok/Tokopedia, TANPA Lazada. Ambang #100 =
  29 unit; 100 SKU = 29.175 unit (95,5% dari 30.550).
- Detail metode, aturan penggabungan, skrip: lihat
  [project-undercover-rampingkan-top100.md](project-undercover-rampingkan-top100.md).

## Cara evaluasi kuartal berikutnya

1. Minta user ekspor BigSeller terbaru (format sama `MOBIL_TERLARIS_BIGSELLER`)
   + listing UA terbaru (Shopee/TikTok/Lazada) utk peta nama->SKU.
2. `repair_xlsx.py` listing -> `sku_map_lib.py` -> `ranking_per_sku.py`
   (cek ulang SPLIT Rocky/Gran Max dari sheet Detail & daftar nama
   "berdiri sendiri") -> `build_ranking_xlsx.py` -> `inject_cache.py`.
3. Bandingkan dgn tabel di atas: SKU keluar (turun ke >100) & masuk.
4. Filter listing: `klasifikasi_listing_top100.py` + `build_listing_top100_xlsx.py`
   (Shopee `mass_update_basic_info`).
