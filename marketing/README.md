# Undercover — Digital Marketing

Folder ini adalah **project root untuk PC Marketing (PC 1)**: social media &
website. Buka folder **`marketing/`** ini di Claude Code (bukan folder `Undercover/`
root — itu punya sisi e-commerce). Lihat [`../SETUP-MULTI-PC.md`](../SETUP-MULTI-PC.md)
untuk penjelasan arsitektur 2-komputer.

## Isi folder

| Folder | Untuk apa |
|--------|-----------|
| `claude-memory/` | Snapshot memory Claude khusus marketing (restore ke device baru — lihat SETUP). |
| `Konten Sosmed/` | Draft caption, ide konten, jadwal posting Shopee/TikTok/Instagram. |
| `Website/` | Copy halaman, artikel/blog, catatan SEO. |
| `Kalender Konten/` | Kalender konten / content calendar. |
| `Aset Brand/` | Guideline brand, referensi logo/warna (aset besar → Google Drive). |
| `scripts/` | Script pendukung (opsional). |

## Aturan penyimpanan

Sama seperti sisi e-commerce: **git hanya untuk teks kecil** (draft `.md`, copy,
catatan). **Aset besar** (video, banner, gambar, `.psd`, dsb) **tidak** masuk git
— simpan di Google Drive (lihat `.gitignore` di root repo dan `SETUP-DEVICE-BARU.md`
di folder ini).

## Toko yang dikelola

Undercover Autocare (UA), Otonation (OT), Otoprotection (OP), Smartprotection (SP)
— jualan cover mobil di Shopee, TikTok, Lazada. (Detail bisnis dipakai bersama
dengan sisi e-commerce, tapi memory-nya terpisah.)
