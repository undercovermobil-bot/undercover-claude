Sisi **Digital Marketing** proyek Undercover dikerjakan di PC 1 (terpisah dari PC
e-commerce), dengan project root Claude Code di folder `Undercover/marketing/`.
Memory-nya sengaja dipisah dari e-commerce supaya konteks tidak tercampur — lihat
`../../SETUP-MULTI-PC.md`.

**Bisnis:** cover mobil ("body cover mobil"), 4 toko — Undercover Autocare (UA),
Otonation (OT), Otoprotection (OP), Smartprotection (SP) — jualan di Shopee,
TikTok, dan Lazada. Bahasa komunikasi & dokumen: Bahasa Indonesia (balas chat
dalam Bahasa Indonesia); istilah teknis/kode tetap Inggris.

**Ruang lingkup marketing (yang dikerjakan di sini):**
- Konten social media: caption, ide konten, jadwal/kalender posting.
- Website: copy halaman, artikel/blog, catatan SEO.
- Aset brand: guideline, referensi logo/warna.

**Konvensi penyimpanan:** git hanya untuk teks kecil (`.md`, copy, catatan). Aset
besar (video, banner, gambar, file desain) → Google Drive, tidak masuk git
(lihat `.gitignore` root repo).

**Hubungan dengan e-commerce:** data bisnis (nama toko, produk) dipakai bersama,
tapi pekerjaan katalog/SKU/harga adalah ranah e-commerce (PC 2, memory di repo
root). Jangan mendesain ulang atau menyentuh aturan SKU dari sisi ini.
