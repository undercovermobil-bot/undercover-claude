## Temuan tuning anti-bot (2026-06-26)
Anti-bot Shopee 2026 mendeteksi browser yang dikontrol Playwright, **bukan** soal login/headless. Diuji 5 konfigurasi, semua kena block (error `90309999` / halaman "Terjadi Kesalahan"):
1. headless + cookie homepage  2. headed + stealth tanpa login  3. headless + login
4. headed + login buka URL search  5. headed + login alur kotak-cari mirip-manusia

Login (`storage_state.json`) berhasil disimpan & melewati login wall, TAPI begitu browser dipakai automation, Shopee menyajikan challenge/error. `curl` polos ke API → 403. Vanilla Playwright tidak tembus tanpa anti-deteksi serius + proxy residensial.

Kode sudah siap pakai begitu ada jalur akses valid — backend scraping diisolasi di `ShopeeScraper`, tinggal swap.
