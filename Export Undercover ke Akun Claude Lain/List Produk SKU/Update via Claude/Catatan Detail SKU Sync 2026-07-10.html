Prioritas: 331 Produk Terlaris

Instruksi 2026-07-11: kerjakan dulu 331 produk di "MOBIL TERLARIS.xlsx" (sheet "COVER MOBIL"), untuk semua toko, sebelum sisa katalog.

Temuan: file lama "MOBIL TERLARIS - Status Update SKU.xlsx" ternyata warnanya sudah basi

File itu punya highlight per-produk (Hijau = sudah ada SKU di master, Kuning/Oranye/Merah = belum, dengan legenda persis di baris 1-5). Setelah dicek ulang terhadap master TERKINI (per toko, bukan digabung), dari 166 baris non-hijau, 163 ternyata alarm palsu (cuma beda ejaan/singkatan dgn nama di master, mis. "Honda HRV" vs master "Honda HR-V / e:N1", "Toyota Altis" vs "Toyota Corolla Altis"). Cuma 3 gap yang genuinely nyata di seluruh 331×4=1.324 kombinasi toko-produk — ketiganya sudah dibuatkan/dilengkapi entri masternya (lihat §5 nomor 02).

01
Tinggi

Review & proses ke e-commerce

Semua perbaikan (UA+OT+OP+SP) ada di folder Update via Claude\ — struktur foldernya sama persis dengan yang asli. File aslinya belum diubah sama sekali. Begitu kamu cek dan setuju, tim produksi tinggal salin file dari situ ke lokasi asli, lalu upload ulang ke Shopee/TikTok/Lazada seperti biasa.

Untuk mass-upload nanti: sertakan HANYA baris yang SKU-nya benar-benar berubah dari versi asli — kalau produk yang tidak berubah ikut disertakan, upload massal berisiko me-reset stoknya (sesuai arahanmu). Tunggu file stok/harga terbaru dari kamu sebelum digabung. Skala: 2.256 baris listing.
